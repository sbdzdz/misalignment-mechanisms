# Code style

- Every function and method gets a docstring with Args and Returns sections, 
one brief line each.
- If argument or return is None, there's no need to add Args or Return to the 
docstring.
- No backticks or quotes around names in docstrings. Write Result, not `Result`.
- Comments should not exceed 79 characters per line. Longer comments should be 
split over multiple lines.
- Comments should be brief.
- Rather avoid in-line comments and don't refer in the comments to any 
instructions given to you.
- Don't add any docstring to main() functions.
